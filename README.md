# 🌷 My E-Portfolio | Psychology Teacher

เว็บไซต์แฟ้มสะสมผลงานส่วนตัว (E-Portfolio) สำหรับนักเรียนหญิงที่มีความใฝ่ฝันอยากเป็นครูด้านจิตวิทยา จัดทำขึ้นเพื่อรวบรวมประวัติส่วนตัว ผลงาน ความสามารถ และกิจกรรมต่าง ๆ ที่แสดงถึงความรู้ ความสามารถ และความตั้งใจในการศึกษาต่อด้านจิตวิทยาและการศึกษา

## ✨ Features

- หน้าแรก (Home) แนะนำตัวและแสดงความใฝ่ฝัน
- แนะนำตัว (About Me) แสดงประวัติและความสนใจ
- ผลงาน (Portfolio) รวบรวมผลงานและความภาคภูมิใจ
- กิจกรรม (Activities) แสดงกิจกรรมและประสบการณ์
- เมนูนำทางใช้งานง่าย
- ปุ่มเชื่อมต่อ GitHub
- รองรับการแสดงผลทั้งคอมพิวเตอร์และโทรศัพท์มือถือ (Responsive Design)

## 🎨 Design

- ธีมสีน้ำตาล ชมพู และครีม
- รูปแบบเรียบง่าย อบอุ่น และเป็นธรรมชาติ
- ใช้ฟอนต์ Prompt รองรับภาษาไทย
- ออกแบบให้เหมาะกับแฟ้มสะสมผลงานนักเรียน

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Prompt)

## 📂 Project Structure

```text
My-Portfolio/
│
└── index.html
```

## 🚀 How to Use

1. ดาวน์โหลดหรือ Clone Repository นี้
2. เปิดไฟล์ `index.html`
3. เปิดเว็บไซต์ผ่าน Google Chrome หรือเว็บเบราว์เซอร์อื่น ๆ
4. สามารถแก้ไขข้อมูลส่วนตัว ผลงาน และกิจกรรมได้ตามต้องการ

## 🌐 Website Deployment

เว็บไซต์สามารถเผยแพร่ผ่าน GitHub Pages ได้โดย

1. เข้าไปที่ Settings
2. เลือก Pages
3. เลือก Deploy from a branch
4. เลือก Branch `main`
5. เลือก Folder `/ (root)`
6. กด Save

## 🎯 Objective

เพื่อจัดทำแฟ้มสะสมผลงานในรูปแบบเว็บไซต์ที่นำเสนอประวัติส่วนตัว ความสามารถ ผลงาน และประสบการณ์ต่าง ๆ รวมถึงสะท้อนความมุ่งมั่นในการก้าวสู่การเป็นครูด้านจิตวิทยาในอนาคต
